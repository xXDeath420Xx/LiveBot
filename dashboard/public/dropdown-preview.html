Dropdown style reference

Every dropdown shape used across the dashboard, rendered against the real surfaces with the real stylesheet. Open each one — the popup list is drawn by the browser, so it is the part that has to be checked visually rather than read off the CSS.

Standard select

Placeholder should read as muted, not as a real choice.
Arrow removed, control dimmed.

Grouped options

Group headers muted; disabled option muted.
Popup scrollbar should be dark, not the OS light default.

Multi-select (renders inline, not as a popup)

Selected rows use the accent tint; no arrow.

Custom (non-native) dropdown menu

Bootstrap-style menus and the user menu in the topbar. Shown open so the surface can be compared against the native popup above — the two shapes should not read as two different design systems.

Datalist input

The datalist popup cannot be styled by the page in any browser — it follows color-scheme only. That is why it is declared on :root.

Surfaces in use

--bg-primary #0b0f11 (control) --bg-secondary #0f1316 (popup) accent tint (selected) #a78bfa (arrow / focus)

Before unification these six near-identical greys were all in use for the popup surface: #1a1d21, #1a1f25, #12141b, #1a1e23, #161b1f, #141a1e — none of them matching --bg-secondary. All now resolve to the token.
