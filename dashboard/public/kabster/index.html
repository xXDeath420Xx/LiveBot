01Four things only you can decide

Everything else is handled. These four need a call from you before we go ahead.

1 · Ko-fi — do you want to keep it?

Kabbot can hand out supporter roles automatically, but Ko-fi guards the key: there's a token only you can copy out of your Ko-fi settings. No bot can fetch it for you.

Either: grab the token and Kabbot takes over supporter roles · or: leave Ko-fi Bot in the server and change nothing.

2 · DISBOARD — do you want the server listed?

DISBOARD only does one thing: it lists your server on a public "find a server" site so strangers can bump into it. It's not a feature we can replace — it's a decision about whether you want to be on that kind of site at all.

Either: keep it and keep the listing · or: remove it and the server goes back to invite-only word of mouth.

3 · Blerp — library, or your own clips?

Kabbot has a soundboard: upload clips, get a panel of buttons, they play into voice. What it can't do is Blerp's giant hosted library of sounds you didn't upload.

If people use Blerp for the library, keep it. If it's a handful of clips, we can move those over and drop it.

4 · Seven spare roles — what should they be?

The cleanup leaves 7 empty roles going spare. We could make them game roles (Fortnite, Minecraft, whatever this server actually plays) — but you know that and we don't. Tell us the names and we'll wire them to a click-to-get panel.

04The role clean-up

The server has 106 roles and a lot of them are ghosts.

There are six roles called "He/Him". Every time Carl-bot's role panels got rebuilt, it made a brand-new set of roles and abandoned the old lot. The pronoun roles exist six times over; the region roles twice. Only one set of each has anybody in it — the rest are corpses cluttering your role list.

05What happens, in what order

  • Settings first — counting, logging, your go-live ping, the games. Config only. Nothing is posted, nothing is deleted, nobody notices.
  • Then the roles — the renames above. Nothing with a person in it is touched.
  • Then the panels — new click-to-get role panels go up. This is the only step that puts messages in the server, so it's a separate, deliberate button. Carl-bot's old panels are left exactly where they are; they just stop working when it leaves, and can be deleted after.
  • Only then, the bots leave — one at a time, and only after every single thing that bot has ever posted has been accounted for by something Kabbot does.
