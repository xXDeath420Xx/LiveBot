HAVENDOCK MODS

Complete Installation & Usage Guide

Downloads Guide

1. Prerequisites

Before installing any mods, you just need the game. The Mod Manager handles everything else automatically.

  • Own Havendock on Steam. Mods are tested against the current Steam release. Epic/GOG may work but are untested.
  • Download the Mod Manager from the downloads page. Extract and run HavendockModManager.exe.
  • BepInEx installs automatically. On first launch, if the mod loader (BepInEx) isn't detected, the Mod Manager will prompt you to install it with one click. It downloads and sets up everything for you — no manual file copying needed.
Where is my game folder? Right-click Havendock in Steam → Manage → Browse Local Files. Typical path: E:\SteamLibrary\steamapps\common\Havendock

2. Installing Mods

There are three ways to install mods. Pick whichever suits you best.

Method A: Mod Manager (Recommended)

The easiest way. The mod manager handles everything: BepInEx setup, downloading, installing, toggling, and configuring mods.

  1. Download the Mod Manager from the downloads page and extract the zip anywhere (Desktop, Documents, wherever).
  2. Run HavendockModManager.exe. It auto-detects your Havendock install and installs BepInEx if needed.
  3. Click "Browse & Install" in the sidebar. The mod catalog loads from our server.
  4. Click "Install" on any mod you want, or "Install All" for everything.
  5. Use the "Installed Mods" page to toggle mods on/off and edit their settings.
  6. Use "Play Modded" or "Play Vanilla" to launch with or without mods.

Method B: Download Individual Mods (Manual)

Download only the mods you want from the downloads page. Requires BepInEx installed manually.

BepInEx required first! Methods B and C require you to install BepInEx yourself before mods will work. Download BepInEx 6.0.0-be.755 (Unity Mono x64) and extract the contents directly into your Havendock game folder (so winhttp.dll sits next to Havendock.exe). Run the game once to generate the BepInEx/plugins/ folder.
  1. Install BepInEx into your Havendock game folder (see above).
  2. Download any mod zip from the downloads page.
  3. Extract the folder (e.g., AudioToggles/) into Havendock/BepInEx/plugins/
  4. Launch the game. The mod loads automatically.
# Example: Installing AudioToggles manually Havendock/ ├── winhttp.dll # From BepInEx zip ├── doorstop_config.ini # From BepInEx zip ├── Havendock.exe └── BepInEx/ └── plugins/ └── AudioToggles/ └── AudioToggles.dll

Method C: All Mods Pack (Manual)

Get everything at once. Also requires BepInEx installed manually.

BepInEx required first! Same as Method B — install BepInEx 6.0.0-be.755 (Unity Mono x64) into your game folder before extracting mods.
  1. Install BepInEx into your Havendock game folder.
  2. Download "All 31 Mods" from the downloads page.
  3. Extract into Havendock/BepInEx/plugins/. You should see 31 folders, one per mod.
  4. Launch the game. All mods load. Disable any you don't want by deleting the folder.
Tip: Method A (Mod Manager) is strongly recommended — it handles BepInEx installation, mod downloads, toggling, configuration, and even vanilla/modded launch switching all in one app. Methods B and C are for users who prefer manual control.

3. Using the Mod Manager

Installed Mods Page

Shows all mods currently in your BepInEx/plugins/ folder. Check/uncheck the box next to each mod to enable or disable it (this renames the .dll so BepInEx skips it). Click a mod to see its description, hotkeys, and live settings editor.

Browse & Install Page

Connects to certifriedmultitool.com to fetch the latest mod catalog. You can search, filter by category, and install/remove mods with one click. Hit "Install All" to grab everything, or pick and choose.

Settings Editor

When you select an installed mod, its BepInEx config file is parsed and displayed as editable controls:

  • Checkboxes for on/off toggles (e.g., EnableAutoReplant)
  • Sliders for numbers with ranges (e.g., SeagullCap: 1-200)
  • Dropdowns for key bindings and enum values
  • Text fields for everything else

Changes save automatically. Restart the game for them to take effect.

Profiles

Save different mod configurations as profiles. Use the toolbar at the top to Save, create New, or Delete profiles. Useful if you want different mod sets for different playstyles (e.g., "Chill Build" with visual mods only, "Full QoL" with everything).

Config files location: Havendock/BepInEx/config/com.havendock.*.cfg — You can also edit these with any text editor if you prefer.

5. Mod Details

Auto Replant

Farms automatically refill their internal seed storage after each harvest cycle. By default, seeds are infinite (the farm's currConsumables resets to max). You can change this in settings to pull seeds from storage instead, which requires you to actually have seeds stockpiled.

Population Cap

Set a hard cap on seagulls and clownfish via settings (default: 20 seagulls, 10 clownfish). When the count reaches the cap, breeding buildings silently skip spawning. They resume automatically when the population drops below the cap. No need to manually toggle incubators.

Resource Reserves

Press - in-game to open the reserve panel. Set a minimum count for any item (e.g., Coffee Bean: 12). When total storage drops to that number, production buildings that consume that item will pause until more is available. The panel shows current storage counts in real-time with red highlighting when reserves are at risk.

Island Compass

Only appears when you're in a boat. Shows two navigation aids (configurable in settings):

  • Compass bar — Skyrim-style horizontal bar at the top showing island markers with directional positioning
  • Minimap — Circular minimap in the bottom-right showing island positions relative to you

Only discovered islands appear. A cinematic name popup displays when you dock at an island.

Blueprint System

Press F7 to open the blueprint panel. To save a layout: hold RightShift and drag to select buildings, then name the blueprint. To place: select a blueprint and press F8 — buildings place relative to your cursor position. Blueprints are saved as JSON files in BepInEx/config/Blueprints/.

Auto Sell Surplus

Press \ to configure per-item keep thresholds. When a trader docks, any items exceeding your threshold are automatically donated to the trader, which earns friendship points. This uses the game's barter system — there's no gold involved.

6. Troubleshooting

Mods aren't loading at all
Make sure BepInEx is installed correctly. You should see a console window briefly when the game launches (or check BepInEx/LogOutput.log). If there's no log file, BepInEx itself isn't loading — reinstall it. Make sure winhttp.dll and doorstop_config.ini are in the game root folder.
A specific mod isn't working
Check BepInEx/LogOutput.log for errors. Each mod logs its load status. Look for lines like [Audio Toggles] v1.0.0 loaded or FAILED: messages. If a patch fails, it usually means the game updated and the method signature changed — check for mod updates.
The mod manager says "Game not found"
The manager scans Steam library folders automatically. If your game is on an unusual drive, try moving it to a standard Steam library location, or install mods manually by extracting zips into BepInEx/plugins/.
Config file not found in the mod manager
Config files are only created after the game runs with a mod loaded for the first time. Enable the mod, launch the game, close the game, then the settings will appear in the mod manager.
Hotkey does nothing in-game
Make sure you're not typing in a text field (chat, search). Most mods disable hotkeys when a text input is focused. Also check BepInEx/config/com.havendock.*.cfg to confirm the key is set correctly.
Game crashes on startup with mods
Remove all mods from BepInEx/plugins/, then add them back one at a time to find the culprit. Or use the mod manager to disable all and re-enable individually.
Mod settings reset after game update
Settings are stored in BepInEx/config/ and persist across game updates. If a game update changes the internal class structure, some mods may need to be updated. Check the downloads page for new versions.
Can I use these with multiplayer?
These are single-player QoL mods. Some (like visual mods, overlays, and audio toggles) should work fine in multiplayer since they only affect your local client. Mods that change game state (auto-replant, population cap, resource reserves) should only be used by the host, as they modify shared game data.

7. Uninstalling

Remove a single mod

Delete its folder from BepInEx/plugins/ (e.g., delete plugins/AudioToggles/). Or use the mod manager's Browse page and click "Remove".

Remove all mods

Delete everything inside BepInEx/plugins/. Your config files in BepInEx/config/ are preserved in case you reinstall later.

Remove BepInEx entirely

Delete the BepInEx/ folder, winhttp.dll, doorstop_config.ini, and .doorstop_version from your game folder. Or use Steam's "Verify integrity of game files" to restore the original state.
