Quick Install

  1. Install BepInEx 6 (Unity Mono) into your Havendock game folder, or use the Mod Manager which installs it automatically
  2. Download individual mods below or the full pack above
  3. Extract each mod folder into Havendock/BepInEx/plugins/
  4. Launch the game — mods load automatically
