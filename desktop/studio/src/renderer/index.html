VOD-safe music

Song requests play only through the CertiFried Music source in OBS, which Studio keeps off your Twitch VOD track, so music is heard live but never saved in the VOD. Studio does this only while a song request command is switched on; otherwise it leaves your OBS audio tracks alone and only lists what it notices.

Desktop Audio is on the VOD track: anything playing on this PC (Spotify, YouTube, games) is saved in the VOD.

What this cannot cover
  • Twitch clips are cut from the live stream, so they contain the music.
  • Kick has no VOD track: whatever Kick receives live is in its VODs. With the obs-multi-rtmp plugin, edit the Kick target and give it its own audio encoder on track 2 (the VOD track) to keep music off Kick entirely.
  • Local recordings use their own tracks and include the music unless you turn on Record without music.

Sound Alerts and Blerp

Their sounds normally play through Windows, so Desktop Audio carries them into the saved VOD. Studio can set their browser sources to "Control audio via OBS", keep them off the VOD track, and let you still hear them, the same way it handles CertiFried Music. It notes the old settings first, so you can put them back. It does not run while you are streaming or recording.

      Using a Galaxy Watch or another Wear OS watch

      A Wear OS watch cannot send heart rate to a PC by itself. A small app on the watch does it, and then Studio reads it straight from the watch. Nothing goes through Pulsoid or your phone.

      1. On the watch, open the Play Store and install Heart for Bluetooth, or another app that says it works as a Bluetooth heart-rate sensor.
      2. Open the app on the watch and start broadcasting. Leave it running while you stream.
      3. Turn on Bluetooth on this PC, choose Find my watch above, then Use this one next to your watch.

      You do not need to pair the watch in Windows Settings. If the watch is not listed, check the app is broadcasting, keep the watch near the PC, and tick Show every Bluetooth device nearby. After that, Studio connects by itself whenever the watch is broadcasting.

      A chest strap, or a Garmin with Broadcast heart rate on, works the same way.

      If you also use Pulsoid, CertiFried can use it when your watch has sent nothing for 10 seconds. Add your Pulsoid token on the dashboard, under Connections.

        Voice

        Say a phrase and Studio runs the automation that listens for it. A voice detector passes on only real speech, so clicks, key presses and game sounds are ignored. Whisper then writes down what you said, on this PC, and Studio compares it with the phrases you set as Voice command triggers on the dashboard. No audio leaves this PC; only the phrase that matched goes to CertiFried.

        Voice commands need Windows.

        Listening

        Off

        80% suits most people. 100% means word for word. Lower it a little if a command is missed because Whisper writes it differently (the voice log shows what it wrote). Raise it if a sentence that only sounds like a command sets it off. A command can also have its own setting on the dashboard.

        70% suits most microphones. Studio scores speech differently from Streamer.bot, so a number copied from Streamer.bot (often 20%) is far too low here and makes commands fire when nobody said them. If a command fires when you did not say it, raise this. If one is often missed, lower it a little, or give that command its own setting on the dashboard.

        Speech recognition

        On an NVIDIA graphics card Studio uses Whisper large-v3-turbo, which is the most accurate. The first time, it downloads about 1.2 GB once: the model from the Whisper project, NVIDIA's CUDA files from NVIDIA, and the graphics card part of Whisper from CertiFried. Every file is checked before it is used. Without an NVIDIA card it uses a smaller model (about 150 MB) on the processor. Windows speech recognition needs no download, but it cannot tell speech from clicks and game sounds, so it is only used when Whisper cannot run.

        Your voice commands

        Set these on the dashboard: an automation with the Voice command trigger. Each command can have its own "how sure" setting and a wait before it can run again (10 seconds unless you change it). If Studio often misses a command, use "Teach Studio how you say it": say it a few times and Studio learns how Whisper writes it when you say it.

          What Studio heard

          Everything the voice detector picked up, newest first (the last 200): how long the speech was, what Whisper wrote down, the command it was closest to, how close, and what happened.           Set up OBS

          Each step changes something in OBS only when you click it, and says what it will change first.

          1. 1. OBS WebSocket

            Studio talks to OBS through OBS's WebSocket server.

          2. 2. CertiFried docks

            Adds three docks to OBS: CertiFried Activity (live events), CertiFried Controls (run automations, counters) and CertiFried Chat (Twitch and Kick chat). Studio writes them into OBS's settings file, keeps your other docks, and first saves a backup copy of that file next to it. OBS must be closed, because it rewrites that file when it closes. Each dock address carries a key that can only show your events and chat and run your automations; you can remove it on the Devices page.

            OBS is running. Close OBS, then choose Add CertiFried docks.

            Add them by hand instead

            In OBS open Docks, then Custom Browser Docks. For each dock, type the name, paste the address, then choose Apply.

          3. 3. CertiFried theme

            Copies three styles, CertiFried, CertiFried Light and CertiFried Sand, into OBS's themes folder. Studio does not switch your theme: afterwards, in OBS open Settings, Appearance, keep Theme on Yami and pick a CertiFried Style. Needs OBS 30.2 or later; restart OBS if they are not listed.

          4. 4. CertiFried overlays

            Your alert box, chat, goals and other overlays from the Overlays tab on the dashboard. Each one is added to the scene on air as a browser source (1920 × 1080) with Control audio via OBS on, so you decide in Advanced Audio Properties whether alert sounds reach your VOD. OBS must be connected.

          5. 5. Starter scenes (optional)

            Creates the scenes you tick, each with a large centred text. Scenes that already exist are left alone. OBS must be connected.
