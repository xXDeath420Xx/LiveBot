# Cat Bot Module — Clean-Room Notice

## Scope

This notice applies to the CertiFried Utility files that implement the cat-catching
minigame:

- `core/catbot/**` — constants, spawn/catch engine, emoji map, stats queries
- `commands/games/cat.js`
- `migrations/144_catbot.js`
- `scripts/catbot-generate-art.mjs`, `scripts/catbot-upload-emoji.mjs`
- the catch hook inside `events/messageCreate.js`

## Provenance

The gameplay concept is inspired by **Cat Bot** (https://github.com/milenakos/cat-bot),
which is licensed under the **GNU Affero General Public License v3.0**.

**No source code, artwork, message text, or other copyrightable expression from that
project has been copied into this repository.** This module was written independently
from a behavioural description of the game.

What is shared with the original is limited to **functional game rules**, which are not
copyrightable subject matter:

- the set of cat rarity tiers and their integer spawn weights
- the derivation of a cat's score as `total_weight / weight`
- time-based per-channel spawning within a `[min, max]` second window
- catching by sending the message `cat`, with a short window for late catchers
- the prism prestige rule (spend one of every type)

Facts, rules of play, and mathematical formulae are excluded from copyright protection
(see 17 U.S.C. § 102(b) and the idea/expression dichotomy). Because no AGPL-licensed
expression is present, the AGPL's copyleft and § 13 network-source-disclosure
obligations do **not** attach to CertiFried Utility.

All cat sprites and emoji used by this module are generated by
