Unified Streaming Page — Layout Options

Consolidating 6 scattered pages into one. Which structure feels right?

A

Tabbed Sections

Horizontal tabs at top: Defaults | Streamers | Teams | Auto-Track | Schedules

Each tab is a self-contained section. "Defaults" holds Live Role, announcement channel, webhook persona, ignored roles, cleanup behavior. "Streamers" is the existing table with stream-ended toggles inline. Clean separation, familiar pattern.

Pros

  • Clean mental model — one tab per concept
  • Familiar Discord dashboard pattern
  • Easy to add more tabs later

Cons

  • Can't see defaults while editing streamers
  • More clicks to switch between related settings
B

Collapsible Accordion Sections

Single scrollable page with collapsible sections: Global Defaults → Streamers → Teams → Auto-Track → Schedules

All on one page, expand what you need. "Global Defaults" starts open. Streamers section shows the table with inline stream-ended toggles. Everything visible in context.

Pros

  • Everything on one page — no tab switching
  • Can keep defaults visible while scrolling to streamers
  • Natural top-to-bottom setup flow

Cons

  • Can get long for guilds with many streamers
  • Less visual separation between sections
C

Hybrid — Sticky Defaults + Tabs Below

Global Defaults always visible at top (compact card). Below that, tabs for: Streamers | Teams | Auto-Track | Schedules

Best of both — you always see your channel/role/webhook settings while managing individual streamers below. Stream-ended behavior is inline per-streamer in the table.

Pros

  • Defaults always in view — never lost
  • Clean tab separation for the detail views
  • Natural "configure once, manage many" flow

Cons

  • Slightly more complex layout
  • Less vertical space for streamer table

What's being consolidated

Currently 6 separate pages:

  • Core Settings → Live Role
  • Announcements → Channel, webhook, message template, ignored roles
  • Streamers → Add/edit/delete subscriptions
  • Stream-Ended → Delete/edit-on-end per subscription
  • Teams → Twitch team subscriptions
  • Auto-Track → Role-based auto-tracking
  • Twitch Schedules → Schedule syncs

Becomes 1 page with sections:

  • Global Defaults — Live Role, announcement channel, webhook persona, message template, ignored roles
  • Streamers — Full table with inline stream-ended toggle per row
  • Teams — Team subscription management
  • Auto-Track — Role-based auto-tracking rules
  • Schedules — Twitch schedule syncs
